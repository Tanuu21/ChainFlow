# ChainFlow — Web3 Command Center

ChainFlow is a modern all-in-one Web3 dashboard for:

- Wallet Tracking
- Risk Scanning
- Live Crypto Prices
- Gas Tracking
- Portfolio Analytics

## Features

- MetaMask Connect
- Live CoinGecko API Data
- Ethereum Gas Tracking
- Wallet Risk Scanner
- Responsive UI
- Web3 Dashboard

## Built With

- HTML
- TailwindCSS
- JavaScript
- Ethers.js
- Chart.js
